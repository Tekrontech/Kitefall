# Play-test checklist

Run `Assets/Scenes/Main.unity`. Use **Settings ▸ Account ▸ Delete local save** to repeat the first-launch flow.

## First launch (spec 3.1)
- [ ] Splash (≈2 s) → Login → Guest warning → Terms + age → Name/country/region → Tutorial.
- [ ] Tutorial: launch, steer up/left/right, pull & release, read wind, cut the dummy (or Skip).
- [ ] First duel vs "Practice opponent" (Easy bot, labelled BOT) → Results → Home with daily reward.
- [ ] Welcome items: 3 Guddi, 1 Rokkaku, 500+ coins, parts, 600 m Sooti, Lakri (Hangar / Workshop).

## Match
- [ ] Intro fly-over → launch meter (perfect window = "PERFECT LAUNCH +10 m").
- [ ] Phase banner Calm → Gust (warning flash on compass) → Storm.
- [ ] Approach ring appears near an enemy line; enemy line turns gold.
- [ ] Crossing a line starts the contest meter; attack names lock; sweet-zone band moves on the tension bar.
- [ ] Cut: sparks, paper, slow motion / replay, cut kite spins and falls, line dangles; feed message.
- [ ] Self-snap after holding the red too long; crash into ground/roofs.
- [ ] Results explain why (height, counter, sweet zone %, tip).
- [ ] Ranked (dev toggle): best of 5 with 20 s loadout break (change dum/charkhi).
- [ ] FFA: respawn with next kite of the stack, crates every 3 min (balloon + radar square), assists.
- [ ] Team Battle: blue/red names, captain (C), no contests with team mates.
- [ ] Last Kite Flying: storm wall shrinks, eliminated → spectating.
- [ ] Pause menu: Resume, Settings, Edit controls (drag + save), Quit (Ranked warning).

## Meta
- [ ] Hangar: select kite/dum/dor/charkhi/stack; locked items show levels; dor < 100 m blocks play; free Sooti refill.
- [ ] Workshop: craft kite, repair (coins / ad), spool, charkhi, tuning slots at mastery 3/7, salvage duplicates.
- [ ] Shop: buy a skin with gems (after earning/test purchase), equip it → new colours in the showroom and match.
- [ ] Season pass: claim free levels; premium locked until bought.
- [ ] Rewarded ads (test overlay): double rewards (once), free repair (3/day), free gems (2/day).
- [ ] Interstitial never in the first 3 days / 10 matches, never after a Ranked loss, never during play.
- [ ] Settings: left-handed, sizes, sensitivity, camera, quality/FPS, volumes, haptics, colour-blind, meter numbers.

## Balance targets to watch (spec 7.6)
Win-rate per dor 47–53 % at equal skill; no dor above 35 % pick-rate; Ranked duel 10–15 min with humans.
