# Kitefall – project rules (read before every change)

- **International game.** Kitefall is for players everywhere, not only South Asia. Menus, branding, art style, words,
  characters, arenas and events must feel welcoming worldwide. Regional culture (Lahore rooftops, Japanese rokkaku,
  Brazilian pipas, Chilean volantines, Guatemalan giant kites…) is shown respectfully as *one of many* kite traditions.
  UI uses plain English action words (Release / Pull / Line / Spool); local kite words are flavour text, not the only label.
  Plan and checklist: `docs/INTERNATIONAL_PLAN.md`.
- **Safety:** kite string is cotton or silk-like thread only – never glass-coated, metal or nylon string, blades or injuries.
- **Fair play:** no pay-to-win; cosmetics never change stats. Economy and combat are server-authoritative.
- **No ads during gameplay.** Original assets only – no brands, real people or copied art.
- **Never put API keys, signing keys or passwords in code or chat.**
- Owner prefers explanations in simple English or Roman Urdu.
- Image list + AI prompts: `docs/Kitefall_Image_Assets.xlsx` (generated by `Tools/ArtList/make_assets.py`; it also regenerates
  `Assets/Scripts/UI/ArtSlots.Generated.cs` and `Assets/Scripts/Editor/ArtSlotKeywords.Generated.cs`). Images are installed in
  Unity with Kitefall ▸ Art ▸ Image Mapper.
- Checks before pushing: `dotnet test Tools/CoreTests`; Unity code must compile in Unity 6.6.
